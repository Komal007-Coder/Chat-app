CHAT APP - kaise chalayein

1) Backend (original, koi change nahi):
   cd backend
   npm install
   node server.js
   (Server http://localhost:8080 par start hoga)

2) Frontend:
   frontend/index.html ko browser mein double-click karke kholiye.
   Dusre user ke liye same file ek aur tab/window mein kholiye.
